Import students from Excel

Import once for each session + subject. The section list is read from your Excel file. Supported columns: Sr.No | Roll No | Student Name | Section. One file can contain multiple sections. Spaces in section names are normalized.

The session is automatically saved as SP2027, MO2027, SP2028, etc. Subject code and subject name are saved for future selection. You can import another subject or session without deleting earlier records.

Excel .xls (Excel 97–2003), .xlsx, or CSV (.csv). No filename changes or internet connection required. Password-protected files are not supported.

Safe re-import: Matching students are updated by session, programme, semester, subject code, section and roll number. Previously saved attendance stays unchanged. A student moved to another section is treated as a separate enrolment, so review transfers manually.

➕ Update Student List — Late Registration

Add late-registered students from a revised Excel file. Match by Roll No + Section within the selected subject. Existing attendance, students and dates are preserved. Students are NR (Not Registered) before their joining date.

After preview, you can change the date separately for every new student. Earlier attendance dates will show NR and will not be marked absent.

Before applying: Download a backup of your current data. Review every new student and joining date. No existing students will be deleted, moved or overwritten.

Attendance report

Percentages use only dates with saved attendance entries. Dates without an attendance record are not counted. Late registrants are NR before their joining dates and do not receive absences for those dates.

Backup & restore

Important: Directly opened .html files can have browser-specific storage restrictions. Don't rely on phone storage as your only copy. Download a backup regularly and keep another copy in a safe location. Opening this HTML file from a different path/browser may not show earlier records.

Attendance folder: Keep this HTML file and downloaded backups in a folder named Attendance on your phone. On browsers that permit folder access, use the Export to Attendance Folder button to save a complete snapshot directly. Otherwise, Chrome will download a backup that you can move into that folder using Files.

Restore adds missing records; for matching student/date records, existing device data is preserved. It does not delete existing data.
